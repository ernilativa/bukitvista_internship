# 📌 Final Project – Data Science Internship at Bukit Vista
This project was carried out as part of my data science internship at Bukit Vista, in collaboration with the Dibimbing.id bootcamp program.

# 🧠 Objective
To identify key factors that influence guest ratings on Bukit Vista properties using machine learning techniques.

# 🔧 Tools & Techniques
Web Scraping: BeautifulSoup & Selenium

Data Processing: Pandas, Feature Engineering (from 20 to 34 columns)

Exploratory Data Analysis: Matplotlib, Seaborn

Modeling: Random Forest Regressor

Evaluation Metrics: RMSE, MAE, MAPE

# 📊 Key Results
RMSE: 0.1186

MAE: 0.0884

MAPE: 1.84%
These results indicate strong model performance for predicting guest ratings.

# 💡 Recommendation
Property features such as Amazing View, Beachfront, and Pool View could be prioritized to increase guest satisfaction and overall ratings.
